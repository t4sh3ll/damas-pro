## ✨ Features

### Core Gameplay
- ✅ Tabuleiro 8×8 interativo
- ✅ Movimento validado de peças
- ✅ Sistema de turnos
- ✅ Capturas múltiplas
- ✅ Promoção a dama
- ✅ Detecção de vitória
- ✅ Timer 10 minutos
- ✅ Desfazer jogadas

### Advanced Features
- 🤖 **IA Minimax** - Oponente inteligente
- 💡 **Sugestões** - Melhores movimentos
- 📚 **Combinações** - 4 posições taught
- 📜 **Histórico** - Registro completo
- 🎨 **Responsivo** - Mobile + Desktop
